# Configuration examples / 配置示例

These examples are not installed or imported automatically. Copy only the items
or settings you want into your user configuration; saving reloads them automatically.
For package imports, preserve the paths relative to your user `config/` directory.

这些示例不会随安装启用，也不会自动导入。只需将需要的条目或设置复制到用户配置中，
保存后自动生效。使用包导入时，保留相对于用户 `config/` 目录的路径结构。
